### [boxxkite](https://github.com/EvAlssment/boxxkite)

A self-hostable, batteries-included Kubernetes sandbox for AI agent code
execution — real pod isolation, a control plane, 4 published SDKs
(Python, JS, Go, Rust), and an MCP server, instead of the raw
container-and-hope most "agent sandbox" projects ship.
